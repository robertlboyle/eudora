Backing up Eudora

File ▸ Back Up Eudora… saves everything into one backup: every message's original bytes (attachments are inside them), your accounts, folders, rules, spam filter rules, settings, signatures, labels, and the window's choices. Use it to keep a safe copy, or to move Eudora to a new computer, Windows, Mac, or Linux, in any direction.

  • Password (recommended): the backup is encrypted, and your mail-server passwords and the keys you typed (Spamhaus, Google Maps, Zoom, Twos, the sync key) go in it. Without a password the backup isn't encrypted, and those passwords are left out unless you accept a strong warning by typing "I agree".
  • Include the search indexes: a quicker restore, a bigger backup. Left out, they are rebuilt after restoring.
  • Parts: one file, or parts of a size you choose (for example 4 GB for a USB stick formatted FAT32).

Microsoft 365, Google, and Zoom sign-ins are never in a backup; you sign in again after restoring.

While the backup runs, the background download waits. The window shows real progress throughout.

Restoring a backup

Choose File ▸ Restore Eudora… (or Restore from a backup in the Welcome window) and pick the backup file. For a backup in parts, pick any one of them. A password-protected backup asks for its password.

The restored mail becomes your library in the usual place. If a library is already there, Eudora asks before replacing it:

  • Replacing the library Eudora has open: the backup is restored beside it first, so the open library is untouched if anything goes wrong. When Eudora next starts, the restored library takes its place and the old one is deleted.
  • Otherwise, choose Switch Now to open the restored library.

Afterwards, sign in again to your Microsoft and Google accounts (Settings ▸ Accounts).

A backup made on a phone isn't complete: it holds only the mail that phone kept, and none of your rules. Eudora warns before restoring one. Use it only when no backup from a Mac, PC, or Linux computer is at hand.

Going back to classic Eudora

If you'd rather use classic Eudora (version 7) again, or want your mail where it can open it, File ▸ Export ▸ Classic Eudora… writes a folder that classic Eudora opens as its mail folder. It's also under Settings ▸ Library, and in the Lookout, Thunderbird-style, Gmail-style, and Yahoo-style looks as Export to Classic Eudora… in their File, Tools, or Settings menu.

Exporting

  1. Choose an empty folder (Eudora suggests Documents\Classic Eudora). It can't be inside Dropbox, OneDrive, or another sync service's folder (their file locking damages mailboxes classic Eudora has open), or inside Eudora's library.
  2. Tick the mailboxes to export. They're listed as the sidebar groups them (your accounts, shared mailboxes, and mail imported from files), each with its address and how many messages it holds. When there's only one it's ticked for you; otherwise none are, and Export stays grayed until you tick at least one. Tick or untick the rules and the address book.
  3. Click Export. The dialog and the status bar count the messages as they're written ("writing message 120,000 of 1,412,000"). Stop ends it; exporting again into the same folder carries on where it stopped. When it's done, Eudora says the export was successful and offers Open Folder, which shows the folder in Explorer (the Finder on the Mac).

Eudora only reads your library while it exports: your mail stays as it is, and downloading carries on. Exporting again into the same folder later brings it up to date (new messages added, moved and deleted ones taken out). To keep it up to date by itself, see Keeping a classic Eudora copy current.

What's in the folder

In.mbx, Out.mbx, Trash.mbx, Junk.mbxClassic Eudora's own mailboxes. Every account's Inbox goes into In, every Sent folder into Out, every Trash or Deleted Items into Trash, and every Junk or Spam folder into Junk: classic Eudora has one of each, however many personalities you have.
Your other foldersEach folder of mail becomes a mailbox (.mbx), and folders that hold other folders become classic folders (.fol). When you export one account, they're at the top, as in Eudora; when you export several, each account's are inside a folder named for the account. Online Archive folders join the mailbox's own, as Eudora shows them.
.toc filesEach mailbox's table of contents: where each message is, its date, sender, subject, status (unread, read, replied, forwarded, redirected, or sent), priority, and label, so classic Eudora shows them as Eudora does.
descmap.pceThe names of the mailboxes and folders in each folder.
AttachEvery attachment, as a file, once per content. Each message lists its attachments with classic Eudora's Attachment Converted: lines.
Filters.pceYour rules, as classic Eudora's filters.
NNdbase.txtYour address book, as classic Eudora's nicknames: each contact's address, name, phone numbers, postal addresses, company, title, and notes.
eudora.iniA first settings file: your return address and name, your other addresses as personalities, and your labels. Written once: classic Eudora keeps its own settings in it from then on. Set up your mail servers in classic Eudora (Tools ▸ Personalities) if you want it to check mail.
Eudora export report.txtWhat was written, and everything left out, with why.
Eudora export.db, Eudora export.lockEudora's record of what it wrote, so the next export or the copy kept current writes only what changed. Classic Eudora ignores them.

How messages are written

Classic Eudora doesn't take messages apart when it shows them: it stores them already taken apart, and so does the export, the way classic Eudora's own importer does. Each message keeps its original headers. Its text is written in classic Eudora's character set (Windows-1252); an HTML message is written between classic Eudora's <x-html> marks. A plain-text message with characters that character set lacks (Greek, Chinese, emoji…) is written as HTML so every character still shows. Pictures shown inside an HTML message are written as attachments, so they're in Attach rather than in the message. A message Eudora can't read is written whole, as stored. Lines are written with Windows line endings, and a line starting with "From " gets a ">" before it, as mail programs expect.

Big mailboxes: classic Eudora can't read past 2 GB of a mailbox (it keeps each message's place as a 32-bit number). So when a mailbox would grow past 1.8 GB, the export carries on in a mailbox beside it, "In (2)", then "In (3)", and so on (the parts of Out keep their mail marked as sent). The room left under 2 GB is for mail classic Eudora fetches or moves itself. A single message bigger than 2 GB can't be read by classic Eudora at all; it isn't written, and the report names it.

Rules classic Eudora can't do

Classic Eudora's filters have two tests and up to five actions. A rule that doesn't fit is left out, and the report names it and says why; nothing is left out silently. These are left out:

  • rules with more than two tests, or more than five actions;
  • rules that start with an "unless" test, or mix "any of the tests" with "unless";
  • rules that run the spam filter (Sort with the spam filter) or a plugin, which classic Eudora doesn't have;
  • rules that file mail into a folder you didn't export, or give a label beyond classic Eudora's seven;
  • rules whose reply is words of their own (classic Eudora replies with a stationery file);
  • rules switched off in Eudora (classic Eudora has no off switch, so they would run).

From the command line and other programs

eudora-cli export-classic FOLDER exports every account; --accounts 2,pat@example.com only those (numbers from eudora-cli accounts, or addresses), --no-rules and --no-contacts leave those out, and --json prints the report as JSON. It ends with exit code 3 when classic Eudora has the folder open. Programs use v1.library.export_classic with the Manage the library permission. See The command line.

Keeping a classic Eudora copy current

For going back to classic Eudora, or using it now and then, Eudora can keep a classic Eudora folder up to date by itself. It's off unless you turn it on.

Turning it on

In Settings ▸ Library, choose a folder (empty, or one you exported to before), then tick Keep a classic Eudora copy current in this folder. The same rules apply as for exporting: not inside Dropbox, OneDrive, or another sync folder, and not inside Eudora's library. Untick it to stop; the folder stays as it is.

What it does

The background download (the part of Eudora that checks mail) writes the copy, the way Export to Classic Eudora writes it:

  • new messages are added to the right mailbox as they arrive (the first copy is written 500 messages at a time, so mail keeps coming in meanwhile);
  • messages moved or deleted in Eudora are taken out of their classic mailbox, and moved ones added where they went;
  • status, priority, and label changes are written to the .toc files;
  • a mailbox is compacted (rewritten without the space of messages taken out) when more than a quarter of it is unused;
  • new folders get their mailboxes, and a folder deleted in Eudora takes its mailbox away;
  • changed rules are written to Filters.pce again, and the address book to NNdbase.txt.

It looks for changes every 5 minutes, and every few seconds while messages are still waiting to be written. Tools ▸ Activity lists it as Keeping the classic Eudora copy current, with how many it wrote and how many still wait, and its Pause button holds it.

One way only

Changes made in classic Eudora don't come back to Eudora. The copy follows Eudora: what you mark, move, or delete in classic Eudora is replaced by Eudora's view the next time the copy is updated. So that nothing is lost:

  • a mailbox classic Eudora changed (mail it checked itself, messages moved into or out of it) is kept beside, renamed "name (changed in classic Eudora date)", and Eudora writes its own again. The renamed one stays in classic Eudora's list of mailboxes;
  • nothing is written while classic Eudora has the folder open. Classic Eudora leaves a file named OWNER.LOK in its folder while it runs; Eudora waits until it's gone and catches up then, and Activity says it's waiting. If classic Eudora stopped without closing properly, the file names a window that no longer exists, and Eudora carries on.

From the command line and other programs

eudora-cli classic-mirror --on FOLDER turns it on (--accounts chooses accounts), eudora-cli classic-mirror --off turns it off, and eudora-cli classic-mirror says how it's set. Programs use v1.library.classic_mirror and v1.library.classic_mirror_set. The choice is kept for this computer only: sync between your computers doesn't carry it.

Sync between your computers

Your mail is already on your servers. Sync carries what the servers can't hold: your rules, spam filter rules, labels, signatures, Views choices, other settings, and how you filed mail that the server doesn't know about (such as Online Archive mail you sorted).

  1. On your first computer: Settings ▸ Downloading and sync ▸ Set up sync on this computer…. Eudora makes a sync key and shows its recovery phrase. Write it down and keep it safe.
  2. On each other computer (and your phone): Join, and type the recovery phrase.

Everything is encrypted with the sync key before it leaves your computer, and stored in your own mail account: a hidden folder in Microsoft 365, an "Eudora Sync" folder on an IMAP server, or a hidden label in Gmail. Nobody else, Planet Networks included, can read it.

How mail is filed travels in each account's own mailbox, to the computers that have that account. Settings travel in chooses which account carries the rest; you can keep a copy in others too. Sync now syncs at once; Repair… asks your other computers for a full copy, if how mail is filed here looks wrong; Show recovery phrase shows it again on a computer that's already set up.

Maintenance and Optimize Library

Maintenance keeps Eudora quick. It checks every folder's counts, repairs any damaged text, gives back the space of deleted mail, merges the search index, and refreshes the database's statistics. It runs in the background and shows each step on the status bar.

By default it runs every day at 3 AM, and only when Eudora hasn't been used for 15 minutes. Change this in Settings ▸ Speed and maintenance ▸ Maintenance: every day, every week (on a day you choose), or only when you ask; the hour; and whether to wait until you aren't using Eudora. Run Maintenance Now runs it at once (also in Activity).

Special ▸ Optimize Library… (Compact Mailboxes… in Classic mode) does the clean-up part by hand, with the option to also compact the database itself (slower; useful after deleting a great deal).

With Keep original messages exactly off, maintenance also removes Microsoft's copies of Online Archive items.

Deleted mail's space comes back when at least a quarter of a storage file is unused; until then the file is left as it is, as rewriting it would cost more than it saves.

Keeping original messages exactly

Settings ▸ Library ▸ Keep original messages exactly, for archive and legal purposes is on unless you turn it off.

What it keeps

Microsoft doesn't give out Online Archive mail as ordinary email. It hands each archive item over in its own format, a package of Exchange's internal fields (sender, recipients, text, attachments, flags). Eudora turns that into an ordinary message, which is what you see, search, reply to, and back up.

With the setting on, Eudora also keeps Microsoft's own copy of each item, exactly as Microsoft sent it, beside the message made from it. You never see these copies. They're for:

  • Archive and legal purposes: a byte-for-byte record of what Microsoft held, in case you ever need to show exactly what a message was.
  • Information an ordinary message has no place for, such as some of Outlook's internal properties.
  • Converting again: if a later version of Eudora reads Microsoft's format better, it can redo a message from its copy without downloading anything.

They take room: about two-thirds of the size of the archive's messages again. A large archive can mean tens of gigabytes.

Turning it off

Untick it, and Eudora asks first, then:

  • removes Microsoft's copies from this computer at the next maintenance, which starts at once (the status bar shows each step), and gives their space back;
  • doesn't keep one for archive mail that arrives later.

It doesn't touch:

  • your messages: every one stays, with its attachments, searchable as before;
  • the Online Archive on Microsoft's server: nothing is deleted there, so each item can still be read from Microsoft;
  • your other computers: each has its own library and its own copy of this setting (sync never carries it, or the copies);
  • backups you already made: they keep the copies. Backups made afterwards are smaller and don't have them;
  • the same message from two of your own sources (for example your old classic Eudora files and Microsoft 365): those are both originals and are always kept.

Turning it on again keeps copies for new archive mail. Copies already removed aren't fetched again.

Space comes back as maintenance rewrites the storage files. A file is rewritten only when at least a quarter of it is unused, so a little of the space may stay until more mail in that file is deleted.

From the command line: eudora-cli drop-exports says how many copies there are and how much room they take; eudora-cli drop-exports --yes turns the setting off and removes them (the download must not be running), then eudora-cli optimize gives the space back.

Keeping only recent mail on this computer

On a tablet or a laptop with a small drive, you may want only recent mail here. On a new computer, the Welcome window asks first, before anything downloads. Later, Settings ▸ Library ▸ Mail kept on this computer chooses how much: move the slider (1 month to 20 years, or Everything), or type any number of days, weeks, months, or years.

This removes mail from this computer only. It never deletes anything from your mail servers. Microsoft 365, Gmail, and IMAP servers keep all your mail, and a longer period brings it back here.

Before you choose

As you move the slider, Eudora says what that period would mean: how many messages are older, how many of them would leave this computer, and how many would stay because they exist only here. Nothing changes until you choose Keep Only This Period… and confirm. Removing more than 10,000 messages also asks you to type REMOVE.

What happens

  • Eudora downloads only mail from that period.
  • Older messages leave this computer, and their space comes back. Each message's server is asked first whether it still has it (Eudora lists each server folder and compares). A message its server can't confirm stays here. So does every message in a folder the server didn't answer for, or in an account that isn't signed in on this computer.
  • From then on, messages are removed as they grow older than the period, with the same check each time.

Never removed

  • Mail that exists only on this computer: POP3 mail (a POP3 server keeps mail only until it's collected, or for the days you chose, so the copy here is often the only one), imported files, and classic Eudora mailboxes.
  • Flagged messages (To Do), and messages with a change still waiting for their server.
  • Your backups. Back up first if you want a full copy kept somewhere.

Getting older mail back

Choose a longer period, or Keep Everything. No confirmation is needed: nothing is removed. Over the next checks, Eudora downloads the older mail again from the servers, folder by folder.

The Online Archive is downloaded only for the period chosen as well.

From the command line: eudora-cli call v1.accounts.keep_preview '{"days": 730}' says what keeping two years would mean; eudora-cli call v1.accounts.download_period_set '{"days": 730}' chooses it ({"days": null} keeps everything).

Speed settings

Settings ▸ Speed and maintenance ▸ Memory for speed: Normal, More, or Most. More memory lets counts, sorting, and folders come back faster on a big library. Eudora uses it only while it's open. A choice more than half your computer's memory is marked.

Help ▸ About Eudora shows how long searches, lists, opening messages, and sending usually take on your computer, and the slowest times.

Statistics

Help ▸ Statistics… (Tools ▸ Statistics… in Classic mode): mail received and sent in the last 30 days, the last 12 months, and ever; your 10 busiest days and the year by weekday; what kinds of mail you get (people, notifications, marketing, spam); and how much space the library takes. It shows the figures counted in the background (once an hour) at once; Count now counts again.

Updates

Eudora looks for a newer version on software.planet.net when it starts and then every 14 days, downloads it in the background, and checks its signature. Then it asks: Restart Now, When I Close Eudora, or Skip This Version. Help ▸ Check for Updates… looks at any time.

Looking sends nothing about you: only Eudora's name and version. Settings ▸ Updates sets how often to look, or never.

On Windows, Eudora installed by its Setup program updates itself. Running a newer Setup by hand over an installed Eudora upgrades it where it is: Setup lists each copy installed on the computer (for you only, or for everyone), marks the one you use, and offers to upgrade it there, keeping your mail, accounts, and settings. Choose another folder only to install somewhere new.On the Mac, Eudora updates itself when it's in a folder you can write to (such as Applications); the new version must carry Planet Networks' signature and Apple's approval, or the old one is kept. On Linux, Eudora updates itself the way you installed it: an AppImage replaces its own file as Eudora closes; a .deb or .rpm asks for an administrator's password, then checks the update's signature again before installing it. Installing the .deb or .rpm also adds Eudora's package repository, so the system's own updates (Software Updater, apt, dnf) offer new versions too; delete /etc/apt/sources.list.d/eudora.sources or /etc/yum.repos.d/eudora.repo to stop that.

Forget Sign-ins

Special ▸ Forget Sign-ins… (Forget Passwords… in Classic mode) lists, and after asking removes, the Microsoft and Google sign-ins and the IMAP, POP3, and SMTP passwords this computer keeps. Your mail and settings stay. Use it before giving a computer away, or to sign in afresh.
