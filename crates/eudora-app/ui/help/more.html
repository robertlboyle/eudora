Privacy

Eudora collects nothing about you or how you use it, and shares nothing with Planet Networks, advertisers, or anyone else. There are no ads, no tracking, and no reports sent by themselves.

Eudora goes online only for what you use: your mail servers, the sign-in pages of Microsoft, Google, and Zoom, the update check (which sends only Eudora's name and version, and which you can turn off), pictures you choose to load, and lookups you've set up (Spamhaus, Google Maps, domain registration dates for the spam filter). Your mail stays on your computer and your own servers.

Eudora's source code is open, so anyone can check that it does only what this page says.

Removed features

Some of classic Eudora's features no longer fit today's mail and computers. They're gone from both Classic and Modern modes. Here is what each was, and what takes its place.

FeatureWhy it's goneInstead
Dial-up networking (Internet Dialup options)Computers are always connected now.Eudora waits for the network and carries on by itself.
Kerberos, RPANo longer used by mail services.Microsoft and Google sign-in; passwords and app passwords over encrypted connections.
Advanced Network (timeouts, buffer sizes, Winsock)Handled automatically.Nothing to set.
Message Plug-ins (EMSAPI) and their settingsThe old plug-in system ran with all of Eudora's powers.Plugins, sealed off and limited to the permissions you grant.
Automation (OLE)Windows-only and unsafe.The command line and the API.
MoodWatchWaits for a better way of judging tone.It's planned to return as a tone check before sending.
Ph and Finger directory lookupsThose services are gone.Your organization's directory in address completion.
File ▸ New FileEudora no longer edits plain text files.Your usual text editor.
File Browser, Link HistoryYour computer and browser do these.Finder or File Explorer; your browser's history.
Tip of the DayThis manual; the installer shows tips while it works.
Payment & RegistrationEudora is free.Nothing to pay.
Status "Recovered"No longer meaningful.Unread, Read, Replied, Forwarded, Redirected.
IMAP Fetch, Remove Cached Contents, IMAP prefixEudora decides what to download, and finds folders itself.The whole mailbox is kept on your computer.
Sending with BinHex or uuencodeEvery mail program reads today's standard (MIME).Old mail using them is still read.
Microsoft's viewer and Internet Explorer options; executables in HTMLUnsafe and outdated.Messages are shown in a sealed frame where scripts never run.
Cool bars, MDI task barOld window styles.Today's toolbar and windows.
Notify ApplicationA rule's Notify me action, and system notifications on phones.

Classic features that changed name: Stationery is message templates; Directory Services is your organization's directory; Task Status is Activity in Modern mode; Compact Mailboxes is Optimize Library; Forget Passwords is Forget Sign-ins.

Reporting a problem or a suggestion

Send bug reports and suggestions to software@planet.net. Say which version you have (Help ▸ About Eudora), on which computer, what you did, what you expected, and what happened. Only what you choose to send is seen, and it's used only for that problem.

Eudora is free and comes with no warranty or support, but the intention is to fix reported problems quickly and to add good suggestions.

About Eudora and its license

Eudora is made by Planet Networks. It's free to use, and its source code is free to examine, change, and improve, under your choice of the MIT or Apache 2.0 license. The source code is published at github.com/patlboyle/eudora, with instructions for building Eudora on Windows, the Mac, and Linux. The license files and the notices for the open-source parts Eudora includes are installed with it.

Eudora honors classic Eudora, created by Steve Dorner and published by QUALCOMM, whose source code the Computer History Museum released. Parts of its design, and its icons, redrawn, come from that code under its BSD license.
