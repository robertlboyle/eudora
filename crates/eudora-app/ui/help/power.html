The command line

Everything Eudora does can also be done from a terminal (PowerShell or Command Prompt on Windows, Terminal on the Mac) with the eudora-cli program installed beside Eudora (called eudora before version 1.0.0, now the name of Eudora's window). It works on the same library; --library FOLDER names another.

eudora-cli --help
eudora-cli search "from:ann invoice"
eudora-cli accounts
eudora-cli backup D:\Backups\Eudora --part-size 4GB

Some useful commands:

search, list, show, foldersFind and read mail.
importImport mbox, classic Eudora .mbx, or .eml files.
msg-to-emlTurn an Outlook .msg file into an .eml (--json: describe it instead). No library needed. See Opening .msg files.
triageWhere the spam filter would put each message, and why. Moves nothing.
rulesList, import, export, or run your rules (--dry-run to try).
mark, labels, signaturesStatus, priority, labels; the label list; signatures.
contactsThe address book, or exported to a file.
backup, restoreBack up and restore (see Backing up Eudora).
export-classic, classic-mirrorWrite your mail, rules, and address book as classic Eudora files, and keep such a copy current (see Going back to classic Eudora).
mail-stats, stats, verifyStatistics; sizes; check every stored message against its checksum.
offline, empty-trash, forget-sign-insAs the menu items of the same names.
local-only [ADDRESS] [--mail local|server] [--calendar local|server] [--contacts local|server] [--json]Which accounts keep their mail, calendar (with To Do), or contacts on this computer only; with an address and a switch, changes that account's choice (what it means).
callAny of Eudora's functions by its API method: eudora-cli call v1.mail.search '{"query": "from:ann"}'. eudora-cli api methods lists them all.

Answers meant for scripts are JSON, and the program ends with a real exit code (0 when all went well). eudora COMMAND --help describes each command.

Commands that change the whole library at once (optimize, backup) need the background download to be stopped; when Eudora's window is open, use the menu items instead, which pause it for you.

Programs that use Eudora (the API)

Other programs on your computer can use Eudora, but only as far as you allow, one permission at a time. Nothing can reach your mail until you grant it.

  1. A program asks: it names itself and says why, and which permissions it wants.
  2. Eudora shows the request. Tick only what it needs: reading headers, reading message text, reading attachments, searching, changing or deleting mail, sending, contacts, calendar, To Do, settings, and so on. Each can be limited to some accounts or folders. Strong permissions start unticked, and Eudora warns when a program could both read your mail and send it.
  3. Every message a program wants to send waits for you: Send, Don't send, or Send, and allow all from it once you trust it.

Settings ▸ Programs and plugins lists every program and plugin with its permissions and when it was last used. Revoke takes its access away. Everything each one does is logged in Eudora (Show the log…); once you trust one, you can log only its changes, or only what was refused.

Programs can never read your passwords, sign-ins, or recovery phrase, nor grant themselves permissions or approve their own messages. The API is reachable only from your own user account on this computer, never from the network, and only while Eudora is open (unless you allow eudora-cli api serve to run without it).

Programmers: the API is described in docs/API.md in Eudora's source.

Plugins

Plugins add commands to Eudora: to the right-click menu of messages, to Tools ▸ Plugins…, and as an action rules can run.

Tools ▸ Plugins… ▸ Install a plugin… installs one from its file. Like any program, it can do nothing until you grant it permissions, and it runs sealed off from your computer: it can't reach your files or the network, only Eudora's API as far as you allowed. A plugin whose maker can't be checked is installed only after a clear warning. A plugin's file changed after you installed it never runs.

In the Plugins window you can switch each one on or off, or remove it.

Plugins aren't available on the iPhone.
