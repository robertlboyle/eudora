Menus

Eudora's menus follow classic Eudora's order: File, Edit, Mailbox, Message, Transfer, Special, Tools, Window, Help. Where the two modes differ, the Classic name is given second. Keys are written for Windows; on the Mac use ⌘ for Ctrl and ⌥ for Alt.

On the Mac, as in every Mac program, the menu bar starts with the Eudora menu: About Eudora, Check for Updates…, Settings…, Services, Hide Eudora, Hide Others, Show All, and Quit Eudora. The Help menu is the Mac's own: its search box finds menu commands, and Eudora Help opens with ⌘+?.

Settings

Every setting is in one window. Open it with File ▸ Settings… (Ctrl+,) in Eudora Modern, Tools ▸ Options… in Eudora Classic, File ▸ Options in the Lookout looks, Tools ▸ Settings in Thunderbird-style, Settings ▸ See all settings (Gmail-style) or Settings ▸ More Settings (Yahoo-style), or the gear on the toolbar. Its pages are listed down the left, and it opens on the page you used last. Save keeps what you changed; Cancel leaves it.

The older commands open the matching page: Personalities and Account Settings open Accounts; Signatures, Filters, and Mail Filter Rules open Mail with their editor over it; Plugins opens Programs and plugins.

Files and folders Eudora uses

The libraryWindows %LOCALAPPDATA%\Eudora\Library; Mac ~/Library/Application Support/Eudora/Library; Linux ~/.local/share/eudora/library. A restored library can be elsewhere; Eudora remembers the one it last opened.
Inside itpacks (every message's original bytes, compressed), eudora.db (folders, accounts, rules, settings), index and header-index (search), Attachments (files you opened or saved), logs/download.log (what the background download did).
The message viewerAttachments it opens, and messages it hands to Eudora's window for Reply or Forward, go in Eudora msg in the system's temporary folder (Windows %TEMP%\Eudora msg), removed after a day.
Passwords and sign-insWindows Credential Manager; the Mac's Keychain; the phone's keychain or keystore. Never in the library.
The programWindows %LOCALAPPDATA%\Programs\Eudora (or Program Files when installed for everyone); Mac Applications/Eudora.app.

Uninstalling Eudora

Uninstalling removes the program, its shortcuts, its PATH entry, and its file types. Your library, settings, and saved passwords are kept, so installing Eudora again later finds everything as it was, with no restore needed.

On Windows, at the end of uninstalling, Eudora asks whether to delete them too. It lists the folders it would delete (your library, Eudora's own folder, and its web view's folder), plus Eudora's saved passwords and sign-ins in Credential Manager. Keep My Data is the default. Delete works only after you type DELETE in the box. Deleting can't be undone: mail kept only on this computer (POP3 accounts, imported files, and old Eudora mailboxes) is gone for good. Mail on Microsoft 365, Gmail, and IMAP servers stays on those servers. Make a backup first (File ▸ Back Up Eudora…) if you might want it again.

Eudora doesn't ask while another copy is still installed on the computer (one for everyone and one for you), because that copy still uses the library, or when uninstalling silently. It deletes only the data of the Windows user who uninstalls it.
