Troubleshooting

Start with Activity (click the status bar): it shows what every background job did last, what's waiting, and the download's latest lines, which usually say what went wrong.

The topics below cover the usual problems. If none fits, see Reporting a problem.

Eudora couldn't finish moving its folder

Before version 1.0.0 Eudora kept your mail in a folder called Eudora 27. The first time a newer Eudora starts, it moves that folder to Eudora in one step, however much mail is in it. Windows won't move a folder while another program has a file in it open, usually an attachment you opened from Eudora in a PDF viewer, Word, or Excel.

When that happens Eudora says which programs (and which files) are in the way, and keeps working from the old folder: your mail, settings, and passwords are all there and nothing is lost. To finish the move:

  1. Close the files it names (or the programs).
  2. Choose Restart Eudora in its message (or close Eudora and start it again). The folder moves as it starts.

Choose Later to go on as you are: Eudora tries again every time it starts. From the command line, eudora-cli says the same and names the programs. The Mac and Linux move the folder whatever is open in it.

New mail isn't arriving

  1. Look at the status bar. "Waiting for the network" means the connection dropped; Eudora carries on by itself once it's back.
  2. Is it paused or stopped? The status bar then shows ▶ Resume. Is File ▸ Work Offline on (an Offline badge)?
  3. Choose File ▸ Check Mail (Ctrl+M).
  4. Is the account checked rarely? See Check every in the Accounts settings.
  5. Was the mail sorted out of the Inbox? Look in Recent Mail, and use Special ▸ Why? (Spam Filter) on it.
  6. "Still working… (a long step)" means the download is busy with something large; it's not stuck. "Stopped" means it stopped unexpectedly; Eudora starts it again by itself.
  7. For a Microsoft or Google account that says it needs signing in, choose Sign in to Microsoft 365 again… or add the Google account again.

Sign-in and password problems

  • IMAP or SMTP refuses your password: many providers need an app password made on their website (Gmail, Yahoo, iCloud, Outlook.com). Microsoft and Google accounts should be added with Sign in with Microsoft / Google instead.
  • Microsoft says an administrator must approve Eudora: your organization allows only approved apps; ask its IT department to approve "Eudora".
  • Changes don't reach Microsoft 365 (Activity shows them waiting): choose Sign in to Microsoft 365 again…; the Accounts settings show what Eudora may do on the server.
  • Encryption errors with an old mail server: the error names the next level to try; see Ports and security.
  • Google sign-in stops after a week: while Eudora's Google connection is in testing, Google asks you to sign in again every 7 days.

POP3 mail isn't coming in

When a POP3 account has trouble, the error in Activity (and from Test in its account window) now says what the server itself answered.

  • “The mailbox is in use by another program”: most POP3 servers let only one program read a mailbox at a time. Another computer's Eudora, a phone, or another mail program set up for the same account by POP3 has it open, or a check is still finishing. Eudora waits and tries again by itself. If it keeps happening, give the computers different check times (Settings ▸ Accounts ▸ Check every), or use IMAP on all but one of them.
  • “Refused the user name or password”, with the server's words: check the password (many providers want an app password made on their website: Gmail, Yahoo, AOL), the user name (some servers want the whole address, others only the part before the @), and that POP3 is turned on for the account (Gmail: Settings ▸ Forwarding and POP/IMAP ▸ Enable POP). Eudora also tries the other common way to sign in (AUTH PLAIN) before giving up.
  • The server can't be reached: the POP3 server Eudora guessed (pop.your domain) may be wrong. Your provider's help page names it; it's often mail.your domain. Port 995 with SSL/TLS, or 110 with STARTTLS.
  • Old servers without the UIDL command are read too: Eudora tells their messages apart by their headers.
  • Mail on two computers: POP3 keeps nothing on the server about what you've read or filed. To read the same account on several computers or a phone, IMAP is better.

A message won't send

Messages that can't go wait in Mailbox ▸ Out and are tried again after 1, 2, 4… up to 60 minutes. The main window's status bar says why each failed.

  • A bad address or From is caught before sending, in the message's own window.
  • Is Work Offline on?
  • Sending from a shared mailbox needs Send As or Send on Behalf rights given by your administrator.
  • A send cut off partway is never repeated by itself, so the message isn't sent twice: check the recipient got it, then use Send now in Out if not.

I can't find a message

  • Search for it: the search covers every account, folder, and year.
  • Look in Recent Mail: it lists what was sorted out of the Inbox lately.
  • Select it and choose Special ▸ Why? (Spam Filter) to see why it went where it did; Activity ▸ Details shows what the rules and the spam filter did, message by message.
  • Look in the Trash (Deleted Items), and use Edit ▸ Undo right after a mistaken move.
  • A fraud's links are switched off on purpose; see Fraud and phishing.

Eudora is slow, or uses a lot of space

  • The first download of a big mailbox takes hours; newest mail comes first, and the window stays usable.
  • Give Eudora more memory: Speed settings.
  • Run maintenance: Settings ▸ Speed and maintenance ▸ Run Maintenance Now.
  • The library holds every message's original bytes, compressed, plus the search indexes. Online Archive mail also keeps Microsoft's own copy of each item, which you can turn off: see Keeping original messages exactly. Help ▸ Statistics… shows where the space goes.
  • Never keep the library in Dropbox, OneDrive, or another syncing folder.

The spam filter sorted something wrongly

  • Good mail in Spam: Not Spam (Ctrl+Alt+J) puts the sender on your whitelist and moves it back.
  • Spam in the Inbox: Spam (Ctrl+Shift+J).
  • Both teach the filter. To change where a kind of mail goes, see Mail Filter Rules: switch a rule off, or give it exceptions.
  • A rule of yours above the spam filter that stops ("Skip the rest") keeps the spam filter from those messages, by design.
