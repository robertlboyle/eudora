What's New

The changes in each version of Eudora, newest first. Help ▸ About Eudora shows what's new in the version you have. Every computer gets the same version number for the same Eudora: Windows, the Mac, and Linux 0.1.5 are the same program.

Version 1.0.1 (November 14, 2026; Windows, Mac, and Linux)

  • Accessibility for blind and visually impaired users: Eudora works fully with screen readers (NVDA, JAWS, Narrator, VoiceOver) and by keyboard alone. Screen readers hear what happens, F6 moves between the panes, every field is named, and columns are moved and sized by keyboard. Every look meets WCAG 2.2 AA contrast in light and dark, and there are text sizes for every window and large buttons. See Accessibility.
  • Natural voices speak: the first Windows version of the natural voices made only silence (a step inside the voice model divided zero by zero). They now speak, Eudora plays them itself, and downloaded voices update themselves. See Accessibility.
  • Read Aloud and natural voices: Eudora reads messages aloud with your computer's own voices, or with natural-sounding voices that are a separate download. Rules can speak or play a sound, and who a message goes to is said before it's sent. See Accessibility.
  • New-mail sounds: classic Eudora's own sound, your computer's, or one of Eudora's chimes. See Settings.
  • Advanced Search: classic Eudora's Find Messages window is back, as a button beside the search box. Build a search from rows of what to look for, with all or any of them, and see the search it makes. New search words too: is:, label:, priority:, and account:. See Advanced Search.
  • Strikethrough and highlight join bold, italic, and underline (Ctrl+Shift+X, Ctrl+Shift+H), and right-clicking in a message you're writing offers every formatting, Cut, Copy, Paste, and spelling. See Formatting.
  • HTML or plain text, with a warning: the message window's HTML / Plain Text switch says exactly what formatting would be lost before switching. See Formatting.
  • Classic Eudora's quoting: replies can quote the original with ">" before each line and be written below it (Settings ▸ Mail ▸ Replies). Hold Shift or Ctrl while clicking Reply to reply the other way just once. See Replying.
  • One line per Enter: pressing Enter in a reply or forward no longer leaves a blank line's space (each new line had been a paragraph, which mail programs space out). See Formatting.
  • Senders whose pictures always show are listed in a window of their own (Settings ▸ Mail), with Find, Add, Remove, Import, and Export, and whole domains can be added. A new choice shows pictures from everyone in your Address Book. See Pictures from the web.
  • Corrected names stick: fix a name in To, Cc, or Bcc and address completion suggests it that way from then on. See Address completion.
  • Replied and forwarded marks now come from Microsoft 365 and IMAP servers, so mail you answered in Outlook or on your phone shows as answered in Eudora, and Eudora's replies show in Outlook. See Replying.
  • Keep an account's changes on this computer only: for each account, choose whether mail, calendar, and contacts changes go back to the server or stay only in Eudora, for a local copy that's independent of the server's. See Keeping changes on this computer.
  • Export to classic Eudora: write all your mail, rules, and address book as classic Eudora's own files, and optionally keep that copy current, so you can go back to classic Eudora at any time. See Export to classic Eudora.
  • Contacts and calendars from CardDAV / CalDAV servers (iCloud, Fastmail, Nextcloud, cPanel, and others), both ways. See Adding CardDAV / CalDAV.
  • Merging duplicate contacts: Find Duplicates, then choose field by field what to keep; merges happen on the servers and can be undone. New contacts go where you expect, and contacts can be moved or copied between accounts. See Contacts.
  • POP3 is sturdier: the server's own reason is shown when it refuses, a mailbox in use elsewhere is waited out, and servers without message ids work. See POP3 problems.
  • Setup upgrades in place: it finds each Eudora installed on the computer, marks the one you use, and upgrades it where it is. Uninstalling now asks whether to keep your mail and settings (kept unless you type DELETE). See Updates and Files and folders.
  • Microsoft 365's own folders that hold no mail (PersonMetadata, ExternalContacts, and Yammer Root) are no longer downloaded or shown. See Mailboxes.
  • Importing explained: the manual now says that importing only adds to Eudora, and what to know when classic Eudora is still open. See Importing old mail.

Version 1.0.0 (November 11, 2026; Windows, Mac, and Linux)

  • The first official release: Eudora is no longer an early release. Everything in the versions below is part of it, and Eudora keeps updating itself as new versions come out.
  • Simply Eudora, everywhere: nothing is called "Eudora 27" any more. Eudora's folder is now Eudora (Windows %LOCALAPPDATA%\Eudora, the Mac ~/Library/Application Support/Eudora, Linux ~/.local/share/eudora), the program is installed in Programs\Eudora on Windows, and your saved passwords and sign-ins are kept under "Eudora". The first time this version starts, it moves everything across by itself, once: your library (instantly, however big it is), your saved passwords and sign-ins, and Eudora's other files. Nothing is downloaded again and nothing needs setting up. On the Mac, macOS may ask once for each saved password whether Eudora may use it: choose Always Allow. A Windows taskbar pin from before points to the old program: pin Eudora again from the Start menu. If another program has a file in the old folder open (an attachment in a PDF viewer, say), Eudora names it, keeps working from the old folder, and moves it once you've closed the file and restarted. See Files and folders Eudora uses and Eudora couldn't finish moving its folder.
  • The command line is now eudora-cli (it was eudora), and eudora is now Eudora's window (it was eudora27). Scripts that ran eudora should now run eudora-cli. See The command line.

Version 0.1.8 (November 11, 2026; source code)

  • Outlook .msg files open in Eudora, quickly: double-click a .msg (or an .eml) and it shows in about half a second in Eudora's message viewer, a small program of its own that never waits for your library or Eudora's window. Reply, Reply All, Forward, Save as .eml, Print, and attachments, with the same safety as Eudora's window: no pictures from the web unless you ask (or the sender is on your always-show list), a fraud's links dead. eudora-cli msg-to-eml converts one from a command prompt. See Opening .eml, .msg, and .ics files.
  • Eudora's source code is public: anyone can read, build, and improve it, at github.com/robertlboyle/eudora, with build instructions and setup scripts for Windows, the Mac, and Linux. See About Eudora and its license.
  • Security notices: alerts from more managed security services (Huntress, Arctic Wolf, Expel, Red Canary, and others) are known as alerts about your own computers, not security advisories, so they don't become Red Alerts. Mail from CrowdStrike, SentinelOne, Sophos, and Arctic Wolf is sorted as notifications or marketing. See Red Alert.
  • Payments Received knows more card processors and payment services (Adyen, NMI, Global Payments, Shopify Payments, Checkout.com, and others), and Red Alert more government senders (Social Security, the FTC, the SEC, the Department of Labor, FINRA). See Views.
  • Classic Eudora's license: the Computer History Museum's BSD license for classic Eudora's source, from which Eudora's classic icons and some of its design come, is now included in full with Eudora.

Version 0.1.7 (November 10, 2026; Windows)

  • Eudora for Windows on ARM: a version of its own for ARM64 Windows computers (Snapdragon laptops, Surface, Copilot+ PCs), running natively instead of through Windows' emulation: faster, and easier on the battery. Download Eudora-Setup-arm64.exe; installed over the usual version, it takes its place and keeps your mail and settings. It updates itself from then on, as the usual version does.

Version 0.1.6 (November 10, 2026)

  • Drag messages out as files: drag messages from the list onto the desktop or into a folder to save them as Outlook .msg files; hold Ctrl or Shift while dragging for .eml files, the original messages exactly, byte for byte. A .msg keeps the header block word for word and every attachment byte for byte, and a signed message whole, as Outlook does. Several messages at once are written in the background, counted on the status bar. Programs can do the same (v1.mail.save_as). See Saving messages as files.
  • New mail no longer falls behind Outlook: Eudora could go an hour without new mail while Microsoft made it wait, because each check asked about every folder of a big mailbox and waited for the calendar, contacts, and To Do to be read back. Now each Microsoft Inbox is looked at every minute, new mail there is checked at once, folders that haven't changed are asked about every 2 hours, and what changed on the server is read back on its own. When Microsoft asks Eudora to wait, the log says so. See Checking for new mail.
  • New mail is unread as it should be: Microsoft 365 mail that arrived straight in a folder other than the Inbox (Bulk, Notifications, Lists, sorted there by the server or by Eudora on another computer) came in marked read until Eudora's hourly look at what's read, so Recent Mail showed it as read. It now comes in unread or read as it is on the server.
  • Today's mail says Today beside its time in the message list.

Version 0.1.5 (November 9, 2026)

  • Opening an attachment never freezes Eudora: however long its program takes to start, Eudora carries on at once; if the program fails to start, Eudora says so. See Attachments.
  • Mail links open in Eudora: Eudora can be your computer's program for mailto: links, so an email address clicked on a web page or in another program starts a new message, with the address, Cc, Bcc, subject, and text the link carries. Choose Eudora once in your system's default apps. See Opening .eml and .ics files, and mail links.
  • Calendar colors: right-click a calendar on the left to choose its color, any color, or its own color again. Eudora's choice only: Outlook and Google keep theirs. See Calendar.
  • To Do lists, shown or hidden, in color: each Microsoft To Do list is under To Do on the left. Click one to show or hide its tasks, and right-click for its color, as with calendars. Lists other people shared with you (a colleague's, a shared mailbox's) start hidden. Each task shows its list's color. See To Do.
  • Flagged email opens from To Do: a flagged email's task has Open Email, found by the message's Message-ID wherever it's filed (before, most couldn't find their message after Eudora's sorting had moved it). When the message isn't on this computer, Find Email searches for it.
  • Gmail asked less: when Gmail asks Eudora to slow down, every Eudora program on the computer waits, even after a restart, and opening Eudora no longer reads every Google calendar and contact again. See Gmail on several computers.
  • Help ▸ About always shows the version, even when the update check can't run.

Version 0.1.4 (November 6, 2026)

  • Calendar changes the server refuses: declining, accepting, or changing a meeting that Microsoft won't let you change (someone else's calendar, say) no longer stops Eudora recording your other changes on the server. Before, one refused change was tried every few seconds, for ever, and moves made on the server went unrecorded; now it's counted and given up, and everything else carries on.
  • Canceled meetings leave the calendar: when someone else cancels a meeting, it's taken off your calendar by itself, as Outlook does (meetings already over stay). Deleting a canceled meeting removes it, and never tries to decline it (Microsoft refuses any answer to a canceled meeting).
  • What's New: this version history, in the manual and in Help ▸ About Eudora, which shows what's new in the version you have.

Version 0.1.3 (November 6, 2026)

  • Mail kept on this computer: choose how much mail this computer keeps, from a month to 20 years or everything, on a slider in Settings ▸ Library (and in the Welcome window, before anything downloads). It shows what each choice would remove and keep. Older mail leaves only this computer, and only once its server confirms it still has it; mail that's only here (POP3, imported files, classic Eudora), flagged mail, and anything not confirmed stays. A longer period brings older mail back. Each slow step says what it's doing, with the seconds so far. See Keeping only recent mail on this computer.
  • Gmail asked far less: Eudora open on several computers no longer makes Google slow your account down. A Gmail account is checked through Gmail's history of changes between one full listing a day, and when nobody has used Eudora for 15 minutes, Gmail is asked at most every 2 hours (Settings ▸ Downloading and sync); using Eudora again checks every account at once. See Gmail on several computers.
  • A Gmail account not signed in on this computer (one restored from a backup): its changes wait, and Eudora says so once, instead of trying every few seconds and giving up.
  • The manual on the Mac: fixed the manual not opening on the Mac ("The manual couldn't be loaded").
  • Linux: the build for PCs now works when made on an Apple-silicon Mac.
  • Windows: the first Windows release since 0.1.1, with everything in 0.1.2 and 0.1.3.

Version 0.1.2 (November 6, 2026; the Mac and Linux)

  • Eudora for Linux: an AppImage, a .deb (Ubuntu, Debian), and an .rpm (Fedora, openSUSE), for PCs and ARM64 computers. They update themselves, and the .deb and .rpm add Eudora's own package repository, so the system's updates include Eudora.
  • Eudora for the Mac: the first release on the website, for Apple-silicon and Intel Macs. The Mac has its own menus: an Eudora menu first (About, Check for Updates, Settings, Hide, Quit), the Mac's Help menu with its search box, and ⌘+? for Eudora Help.
  • The user manual: Help ▸ Eudora Help (F1) opens a complete manual: getting started, every task, a reference of every menu, shortcut, and setting, troubleshooting, and what classic Eudora features were removed, with search and an A to Z index. It opens at the page for what you're looking at.
  • One Settings window: every setting in one window, a page at a time (Accounts, General, Mail, Calendar, To Do, Downloading and sync, Library, Speed and maintenance, Programs and plugins, Updates). File ▸ Settings… (Ctrl+,) and File ▸ Accounts…; Personalities, Signatures, Filters, and Plugins open their page. See Settings.
  • Menus that follow the look: the Lookout looks have Outlook's menus and shortcuts (Ctrl+F forwards, Ctrl+E searches, F9 sends and receives), Thunderbird-style has Thunderbird's, and Gmail-style and Yahoo-style a short menu bar in their own words. See Menus in the other looks.
  • Search where you choose: a magnifying glass beside each account and folder leaves it out of search with a click (a red line across it), and a switch on Accounts or Shared Mailboxes covers everything under it. While anything is left out, a magnifying glass with ! beside the search box includes everything, and results say how many more are in the mailboxes left out. See Leaving mailboxes out of search.
  • Delete a whole series: deleting a repeating meeting offers This meeting or The whole series. See Calendar.
  • Keep original messages exactly (Settings ▸ Library, on by default): turned off, Eudora stops keeping Exchange's own copy beside each Online Archive message, and gives back that space (65 GB on one large mailbox). The archive stays on Microsoft's server. See Keeping original messages exactly.
  • Optimize Library rewrites the message files hundreds of times faster.

Version 0.1.0 (November 4, 2026; Windows)

The first public release, an early release for testing.

  • Every account in one place: Microsoft 365, Outlook.com, Gmail and Google Workspace, IMAP, and POP3, with shared mailboxes and the Online Archive, in one library with one search. Imports classic Eudora folders, mbox, and .eml files.
  • Fast with tens of millions of messages: instant search with Outlook's search words and any header, lists that open at once, sorting by any column, and everything working offline.
  • An inbox for people: a spam filter that learns, fraud warnings, marketing, notifications, and mailing lists sorted aside, Recent Mail for what was sorted away lately, Views (Receipts, Invoices, Red Alert, Travel…), rules, and Subscriptions with Unsubscribe.
  • Calendar, contacts, and To Do from Microsoft and Google, with trips added from travel email.
  • Looks: Eudora Classic, Eudora Modern, and looks in the style of Outlook, Thunderbird, Gmail, and Yahoo Mail, with dark mode.
  • Back up and restore everything to one file, including restoring from the Welcome window and replacing the library Eudora has open.
  • Updates itself, checking each new version's signature first.
